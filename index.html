Red-black tree operations

A red-black tree stays balanced by painting nodes and rotating small pieces. Watch two insertions: one fixed by recoloring, one by rotating.

The rules

  1. The root is black.Broken now
  2. A red node never has a red child.Broken now
  3. Every path from the root down to a NIL leaf has the same number of black nodes.Broken now

Key idea

A red-black tree is a binary search tree that obeys the three rules above. Those rules force the longest path to be at most twice the shortest, so the height stays within 2 · log₂(n + 1) and search, insert and delete all take O(log n).

Insertion always paints the new node red, then fixes a red-red clash by looking at the uncle (the parent's sibling):

  • Red uncle: recolor parent and uncle black, grandparent red, and continue from the grandparent.
  • Black or NIL uncle: rotate (once if the new node is on the outside, twice if it is on the inside), then swap colors. The fix ends there.

Deletion uses the same tools, recoloring and rotating, plus an extra "double black" repair when a black node is removed.
